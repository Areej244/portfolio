Personal Portfolio Website

A modern, fully responsive personal portfolio website for Areej Khan, a BS Computer Science student. It presents my profile, skills, education, projects and contact information in a clean, professional design.

Task: Devixo Solutions Web Development Internship, Task 01

Technologies Used
HTML5
CSS3

No Bootstrap, Tailwind, templates or other frameworks were used. All HTML and CSS is my own work.

Website Features
Responsive layout for desktop, laptop, tablet and mobile
Sticky navigation bar with smooth scrolling between sections
Hero section with name, tagline, profile image and call-to-action button
About, Skills, Education and Projects sections
Skill cards and project cards with hover animations
Contact section with a contact form UI
Footer with quick navigation links and social links
Dark theme with a fine grid background and a single blue accent colour, set once in CSS variables
Semantic HTML and clean, organised CSS
